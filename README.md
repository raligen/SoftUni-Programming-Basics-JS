# SoftUni-Programming-Basics-JS
This is a directory where I will be committing my homework and additional exercises from the SoftUni's course.
The 'Programming Basics' course lays the foundations of programming, giving the skills required for each of Softuni's tech degrees. It covers writing source code (basic coding skills), working with an IDE, correct use of variables and data, operators and expressions, reading input and printing output, conditional statements (if and if-else) and loops (for and while). A practical exam in the end of every PB course serves as an entry exam for the SoftUni's software development program.
